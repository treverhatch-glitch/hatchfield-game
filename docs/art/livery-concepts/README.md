# Livery concept sources

Side and top views for the five base roster carriers. The game does not load these JPEGs. `docs/art/LIVERIES.md` records what was sampled into the live palette and the tail decal.

| File | Carrier | Use |
| --- | --- | --- |
| `puddle_jumper.jpeg` | `air_regional_1` | Side palette and tail emblem. Live. |
| `puddle_jumper_top.jpeg` | `air_regional_1` | Crown and wing for the isometric camera. Live. |
| `skycheap.jpeg` | `air_lowcost_1` | Side palette and tail emblem. Live. |
| `skycheap_top.jpeg` | `air_lowcost_1` | Crown and wing for the isometric camera. Live. |
| `prestige_air.jpeg` | `air_fullservice_1` | Side palette and tail emblem. Live. |
| `prestige_air_top.jpeg` | `air_fullservice_1` | Crown and wing for the isometric camera. Live. |
| `national_airways.jpeg` | `air_flag_1` | Side palette and tail emblem. Live. No top view was supplied. |
| `heavylift.jpeg` | `air_cargo_1` | Side palette and tail emblem. Live. No top view was supplied. |

Nothing in this folder is concept-only. The names match airlines that already fly.
