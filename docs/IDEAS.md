# Hatchfield — Ideas

Parking lot for features that deepen the four loops. Nothing here is committed until it lands in [NEXT.md](./NEXT.md).

## Layout skill (steal from Airport CEO verbs)

- **Baggage belt lite** — paint check-in → makeup → bay; broken path = late bags + heat.
- **International zone** — passport room; intl flights need it; domestic uses secure only.
- **Franchise brands** — CounterBite / SkyGlass: sign fee → hall spend mult + rare brand crisis.
- **Custom terminal painter** — walls rewrite the hall graph (skill ceiling; after belts).
- **Stairs / belt loader GSE** — visible boarding hardware on widebody/heavy.

## Growth silhouette (steal from AT3)

- **Scenarios** — timed goals on preset sites (“4 contracts”, “cargo Kiln”, “Guard neighbor”).
- **More sites** — tourist / military town / megacity (weather + demand mix).
- **Terminal ladder look** — multi-story / mega hall silhouette (art + stand counts), not just N shells.
- **Master vs per-flight contracts** — optional renewals on the timetable.
- **True parallel runway ATC** — crosswind / independent parallel polish.
