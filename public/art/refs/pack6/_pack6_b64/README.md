# Pack6 base64 sidecars

JPEG binaries could not be pushed over the box git HTTPS remote (no credentials).
These ASCII `.b64` sidecars decode to the real max-1600px q85 JPEGs:

```bash
python public/art/refs/pack6/_pack6_b64/unpack.py
```

Full-res sources also live in Drive (Concept Renders + Textures) and on the box at `/workspace/hatchfield/assets/pack6/`.
